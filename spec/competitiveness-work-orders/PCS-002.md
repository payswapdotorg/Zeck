## Objective

Implement the `SemanticFidelityFacts` typed artifact in the capability plane, exactly as ACR-009 §2 specifies. This is the PURE PLANE: types, validation, determinism, closed vocabulary, provenance, absence-equivalence. NO planner gating (that is PCS-003) and NO evaluation changes (that is PCS-004).

## Required deliverables

1. **`SemanticFidelityFacts` artifact** (in the existing capability plane — study `src/platform/` capability modules and the compat capability registry first; suggested `src/platform/capabilities/semantic-fidelity.ts`):
   - the closed fact block: representation kind (`semantic-model-backed` | `deterministic-substitute`), modality (closed enum where relevant), dimensionality (typed positive integer), normalization (closed enum: none | l2 | scale-bounded), similarity semantics (closed enum: cosine | dot | exact-match-lexical | hash-proximity), quality contract (the task-authored declared requirement or its explicit absence), compatibility constraints (the closed list: dimensionality-match, normalization-match, similarity-semantics-match);
   - every field closed and typed; unknown values fail closed at the boundary with a typed error naming the field and the offending value — never a default, never a widening;
   - explicit provenance on every fact: which execution, which declared capability, which substitute identity (the explicit-basis CostClaim discipline applied to semantic facts);
   - the fact block is OPTIONAL on the capability/execution representation: absent = the byte-identical-today state (absence-equivalence, discrimination-tested at the representation level).

2. **Boundary checking** (pure, no wiring):
   - the compatibility constraints check mechanically at the delegation boundary when both sides declare facts (consumer constraints vs producer facts): every mismatch is a typed failure naming both sides; absence of either side's facts skips the check exactly as today (absence-equivalent);
   - determinism (invariant 5): same facts → byte-identical validation verdict; content-addressable fact identity for evidence correlation.

3. **Tests** (the established discipline — study the existing capability-plane suites first):
   - unit tests for every field's closed vocabulary, every fail-closed path, provenance completeness and determinism;
   - discrimination tests: absence-equivalence (the fact block absent → byte-identical representations and validation verdicts vs the pre-change baseline), unknown-value fail-closed, boundary mismatch typing;
   - architecture tests proving no new durable surface, no new capability family, no registry widening (the family census is frozen), no ambient configuration;
   - the full existing battery stays green.
