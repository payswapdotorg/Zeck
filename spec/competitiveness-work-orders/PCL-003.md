## Objective

Deliver the P3 program's evidence: the evaluation proving the tail mechanics do what ACR-010 §5 requires — per-failure-class p50/p95/p99, total cost including duplicate attempts, resolution rate and verification cost per configuration, the promotion gate (never median alone), and the honest replay of the PPR-027 capstone's latency cells under the gated configuration.

## Required deliverables

1. **Evaluation application** (`benchmarks/validation/apps/` in the established pattern; TRUE work-order tag `PCL-003` on the README first line; seam helpers via the lab's shared re-export):
   - **per-failure-class percentile reporting**: p50/p95/p99 for each failure class and route, computed ONLY from the PCL-001 typed facts (never aggregate-only reporting);
   - **cost truth**: total cost including duplicate attempts and verification cost per configuration (the explicit-basis discipline);
   - **resolution honesty**: resolution rate and verification outcomes per configuration — a tail improvement that costs resolution is a MISS;
   - **the promotion gate, mechanically applied**: (tail percentile improvement) AND (no resolution regression) AND (cost within the declared budget delta) AND (timeout/terminal-failure behavior preserved) — median improvement alone promotes NOTHING;
   - **replay of the PPR-027 latency cells**: the capstone's latency cells re-run under the typed-facts configuration with honest per-cell verdicts; the recorded capstone-era results quoted verbatim, never relabeled; synthetic-supply labels preserved.
2. **Threshold report** (the declared-before/verdict-after discipline): explicit thresholds declared BEFORE the run, honest verdicts after (a threshold miss with attribution is a VALID delivery); reproducibility digests pinned, re-run byte-identical; wall-clock and run identities excluded from every digest projection.
3. **Validation suites** (`tests/unit/validation/pcl-003-*.test.ts`): construction laws, percentile computation correctness against known fixtures, census reconciliation (attempts = originals + retries + fallbacks + verifications — dropped or reclassified failures are an automatic void), promotion-gate application, digest reproducibility.
