## Objective

Deliver the P3 program's mechanics: the existing execution pipeline's pacing parameters — retry delays and backoff shape, provider cooldown entry/exit by failure class, status-polling interval and compression, and event-vs-polled progress delivery — become declaratively configured, typed quantities (ACR-010 §3), introduced default-off and absence-equivalent (§4): with no configuration authored, every existing call site, test and evidence record is byte-identical to today.

## Required deliverables

1. **The declarative pacing configuration** (a typed, closed, versioned configuration object at the existing execution seam — data, never an engine):
   - retry pacing: bounded, jittered backoff with a declared ceiling; shape and bounds are configuration data;
   - cooldown discipline: failure-class-aware provider cooldowns with explicit re-entry (a throttle cools differently than a 5xx);
   - progress delivery: event/stream subscription where the transport's typed capability facts support it, polled as the honest fallback; the polling interval a declared quantity;
   - the timeout/terminal-failure preservation gate: a configuration that would mask a terminal failure as success, or extend a declared timeout beyond its contract, is REJECTED typed at the configuration boundary (fail-closed).
2. **The wiring** (the existing pipeline reads its pacing from the configuration; NO second router/planner/executor):
   - absence-equivalence proof over the real wired stack: the baseline (no configuration authored) captured BEFORE the change, byte-compared after (the PCR-002/PCS-003 pattern — the traced decision/execution table);
   - discrimination tests: each mechanics dimension on/off via the declared configuration only (no ambient flags);
   - the outcome record carries the mechanics actually applied (progress mode, polling interval, cooldown state at dispatch) through the PCL-001 facts, read-only consumption.
3. **Tests**: unit + discrimination + architecture suites covering every configuration path, the fail-closed malformed/timeout-violating rejections, and the absence-equivalence byte-identity; the full existing battery stays green.
