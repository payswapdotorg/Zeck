# VAL-026 — Outcome-State Correctness and Side-Effect Verification

**Status:** AUTHORIZED / PENDING
**Program:** Zeck Validation Roadmap
**Assurance:** HIGH_ASSURANCE
**Dependencies:** VAL-002, VAL-003, VAL-004, VAL-006, VAL-009, VAL-010, VAL-019

## Objective

Deliver the outcome-correctness slice: an outcome-state application
exercising side-effect verification end to end — declared effects (the
fixture-state oracle pattern proven across the crowns: workspace trees,
order placements, ticket routings, citations) verified mechanically
against the REAL world state after completion; partial-failure semantics
(a FAILED execution's declared effects must NOT have been applied —
atomicity of the verification boundary); effect idempotency (a replayed
execution applies zero new effects); and outcome-state reconciliation
(the terminal state, the verification criteria, the journal and the
fixture state agree — a COMPLETED execution with a FAIL criterion is
unrepresentable, per the anyFail→FAILED invariant proven in the crowns)
— over the REAL platform path with REAL provider dispatches where the
effects demand them.

## Acceptance criteria

1. The application rides the public SDK boundary with a
   repository-reproducible, secret-free configuration and executable
   tests; the corpus declares, per row, the expected terminal, the
   declared effect set and the expected fixture-state delta (including
   the empty delta for FAILED rows).
2. Deterministic fixtures make every offline row reproducible.
3. A REAL end-to-end integration run (env-gated) drives a pinned corpus
   slice over the REAL platform path: completed rows verify their full
   effect set against fixture state; failed rows verify the ABSENCE of
   their effects; replayed executions verify zero new effects.
4. Reconciliation is verified mechanically: terminal ↔ criteria ↔ journal
   ↔ fixture-state agreement asserted per row; the invariant
   anyFail→FAILED is probed adversarially (a fabricated pass-with-fail
   must be unrepresentable).
5. Honest economics and latency; payload digests (never payloads) in
   evidence.
6. Discrimination tests prove the reconciliation against controlled
   fakes (effect-set mismatch, phantom effects, missing effects, journal
   disagreement).
7. Evidence document records REAL outcomes, timings, costs, NOT RUN
   boundaries and the executed battery honestly.
