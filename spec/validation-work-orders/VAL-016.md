**Status:** AUTHORIZED / PENDING

## Objective

Deliver the customer-style application portfolio slice for video/media generation: a text-to-video application and a media-generation job application exercising asynchronous submission → polling → retrieval over a REAL generation rail (the operator-authorized dashscope-international video-synthesis async task API), integrated through the public SDK boundary, proven end to end against the REAL platform path with mechanically verified outcomes, full evidence capture and honest NOT RUN boundaries where authorized access does not exist at run time.

## Acceptance criteria

1. The applications ride the public SDK boundary with repository-reproducible, secret-free configurations and executable tests.
2. Deterministic request fixtures (seeded prompts, fixed generation parameters) make every dispatch reproducible at the request level; no external media.
3. A REAL end-to-end integration run (env-gated on the authorized video-generation credential) drives a pinned corpus slice through submission → lifecycle → REAL async generation dispatch → poll/retrieve → mechanical verification → assertions → recorder-consumable evidence, including the honest handling of task-failure terminal states.
4. Generated outputs are verified mechanically (valid container, non-empty payload, digest capture, declared duration/dimension bounds where the rail reports them), never against aesthetic judgment; async job semantics are verified against the platform's job/lifecycle expectations (submitted → running → terminal, no lost tasks).
5. Honest economics and latency (async wall time and poll cadence measured); payload digests (never payloads) in evidence.
6. Discrimination tests prove derivations against controlled fakes (fixture digest mismatches, wrong-modality requests, provider failures, malformed containers, task-failure terminal states).
7. Evidence document records REAL outcomes, timings, costs, NOT RUN boundaries and the executed battery honestly.

## Evidence / issue protocol

Report defects with reproduction, classification, solutions, recommendation and verification plan.

## Completion

Complete only after all criteria are evidenced, the PR is merged and validation state is finalized.
