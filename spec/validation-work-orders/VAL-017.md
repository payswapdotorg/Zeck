## Objective

Deliver the customer-style application portfolio slice for visual and audio understanding: real applications (image-recognition/classification, VLM question-answering over images, audio-understanding/transcription) integrated through the public SDK boundary, proven end to end against the REAL platform path with REAL multimodal model completions (open-weights vision routes through the operator-authorized OpenRouter access; the operator-authorized dashscope-international access for audio understanding), mechanically verified outcomes, full evidence capture and honest NOT RUN boundaries.

## Acceptance criteria

1. The applications ride the public SDK boundary with repository-reproducible, secret-free configurations and executable tests.
2. Deterministic synthetic media fixtures materialize exactly per the VAL-003 fixture recipes (in-code generation; no external media).
3. A REAL end-to-end integration run (env-gated on the authorized vision-capable credential) drives a pinned corpus slice through submission → lifecycle → REAL multimodal dispatch → mechanical verification → assertions → recorder-consumable evidence.
4. Vision answers are verified against deterministic ground truth (color/shape/object facts of the generated fixtures); audio understanding verified by transcription round-trip where access exists, else a classified NOT RUN boundary.
5. Honest economics and latency; payload digests (never payloads) in evidence.
6. Discrimination tests prove derivations against controlled fakes (fixture digest mismatches, wrong-modality requests, provider failures).
7. Evidence document records REAL outcomes, timings, costs, NOT RUN boundaries and the executed battery honestly.

## Evidence / issue protocol

Report defects with reproduction, classification, solutions, recommendation and verification plan.

## Completion

Complete only after all criteria are evidenced, the PR is merged and validation state is finalized.
