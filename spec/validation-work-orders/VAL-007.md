# VAL-007 — Longitudinal Experiment Ledger and Immutable Run Identity

**Status:** AUTHORIZED / PENDING
**Program:** Zeck Validation Roadmap
**Assurance:** HIGH_ASSURANCE
**Dependencies:** VAL-001, VAL-004

## Objective

Build the longitudinal experiment ledger: an append-only registry of experiments (repeated workload replays, learning trials, shadow/canary comparisons) that binds immutable run identities to experiment cohorts so trajectory and economic evolution over time is analyzable and reproducible.

## Allowed surfaces

- `benchmarks/validation/ledger/**`
- validation schemas/tests
- `docs/work-items/VAL-007.md`

## Forbidden

- mutating or deleting recorded experiment history;
- rebinding run identities across experiments;
- claiming longitudinal effects without recorded cohorts.

## Acceptance criteria

1. Experiments register with stable identities, declared hypotheses and cohort membership.
2. Runs attach to experiments immutably (append-only; corrections are revisions).
3. Experiment cohorts support repeated-replay analysis (same corpus slice, frozen application revisions, controlled repetition counts).
4. The ledger exports cohort datasets for the learning and economics stages.
5. History integrity is checked mechanically (tamper detection via digests).

## Evidence / issue protocol

Report ledger defects with reproduction, classification, solutions, recommendation and verification plan.

## Completion

Complete only after all criteria are evidenced, the PR is merged and validation state is finalized.
