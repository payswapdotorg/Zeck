# VAL-040 — Economic Baseline Normalization and Fixed-Quality/Fixed-Cost Experiment Protocol

**Status:** AUTHORIZED / PENDING (eligible now: VAL-005, VAL-006, VAL-008 all complete; dispatched in parallel with the longitudinal wave under disjoint surfaces — this slice owns `apps/economic-baseline/**` only and never touches `platform/**` or `apps/shared/**`)
**Program:** Zeck Validation Roadmap
**Assurance:** HIGH_ASSURANCE
**Dependencies:** VAL-005, VAL-006, VAL-008

## Objective

Open the economic-validation wave by making economic measurements
COMPARABLE across arms, and by freezing the experiment protocol every
later economics work order (VAL-041 direct-provider controls, VAL-042
optimized non-Zeck baseline, VAL-043 competing stack) must execute.
Deliver the economic-baseline slice: a normalization library that
converges heterogeneous provider economics (per-token list pricing in
mixed currencies/units, metered vs. batched metering, retry/failure
amortization) onto the program's canonical basis — micro-USD cost per
SUCCESSFULLY resolved outcome, measured facts only, estimates reported
separately and never conflated (the VAL-006 accounting discipline);
the fixed-quality / fixed-cost experiment protocol — fixed-quality arms
pin a declared resolution/quality threshold and measure the cost to
attain it, fixed-cost arms pin a cost budget and measure the quality
attained within it, both with pre-registered corpus slices, minimum
sample sizes and Wilson confidence intervals; and the pinned price
manifest — content-addressed provider list-price tables (digests over
the pinned tables, never prices copied inline) so every later arm
declares WHICH pinned revision priced its runs.

The verification core is the normalization oracle: a mixed-currency
conflation, an estimate-backed cost-per-resolution, a post-hoc arm
exclusion, an unpinned price table and a threshold-gamed fixed-quality
claim each FAIL mechanically. Live rows (env-gated, BYOK, measured —
never fabricated) drive one REAL fixed-quality + fixed-cost experiment
pair through the REAL platform path with economics measured by the
REAL accounting rails; offline rows replay recorded VAL-006-style
accounting records deterministically.

## Acceptance criteria

1. The application rides the public SDK boundary with a
   repository-reproducible, secret-free configuration and executable
   tests; the corpus declares, per row, the arm manifest entry (arm
   kind, pinned price revision, corpus slice, statistical minimums)
   and the expected normalized outcome the protocol derivation must
   reproduce.
2. Deterministic fixtures make every offline row reproducible; the
   price manifest is content-addressed (digests over pinned provider
   list-price tables, never the tables copied into the slice; a
   correction is a NEW manifest revision, never an edit).
3. A REAL end-to-end integration run (env-gated) drives one
   fixed-quality experiment and one fixed-cost experiment over the
   REAL platform path: runs complete, their economics are measured by
   the REAL accounting rails (micro-USD, measured-facts-only), and the
   normalized comparisons (cost-per-resolved, quality-attained,
   confidence intervals) are recorded through the REAL recorder.
4. Mechanical verification per row: normalization integrity (every
   arm's heterogeneous pricing converges to the canonical micro-USD
   per-resolved-outcome basis — a mixed-currency row FAILS to
   normalize), protocol conformance (arm declarations validate against
   the frozen grammar; minimum samples enforced; Wilson confidence
   carried), manifest integrity (digest agreement between declared
   revision and pinned table) — probed adversarially (a mutated price
   entry, a below-minimum arm and a confidence-less comparison each
   FAIL mechanically).
5. Honest economics and latency (measured on the live rows,
   none-reported honestly offline); payload digests (never payloads)
   in evidence.
6. Discrimination tests prove the normalization and protocol against
   controlled fakes (mixed-currency conflation, estimate-backed
   cost-per-resolution, post-hoc arm exclusion, threshold gaming on a
   fixed-quality arm, unpinned pricing, sample-size violation).
7. Evidence document records REAL outcomes, timings, costs, NOT RUN
   boundaries and the executed battery honestly.
