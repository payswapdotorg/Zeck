# VAL-021 — Duplicate, Replay, Retry, Escalation and Continuation Validation

**Status:** AUTHORIZED / PENDING
**Program:** Zeck Validation Roadmap
**Assurance:** HIGH_ASSURANCE
**Dependencies:** VAL-002, VAL-003, VAL-004, VAL-006, VAL-009, VAL-010, VAL-019

## Objective

Deliver the reliability slice for submission-level semantics: an
idempotency-and-continuation application exercising duplicate submissions
(same idempotency key + same fingerprint → replay, zero new effects),
conflicting replays (same key + different fingerprint → the platform's
typed rejection), retry storms (bounded, journaled exactly once per
attempt), escalations (route to the escalation authority with the full
causal chain) and continuations (resume a wait-user execution exactly
once; stale-worker denial; no-op resume replay) — over the REAL platform
path with REAL PostgreSQL (the idempotency ledger, the executions state
machine and the journal are the system under test), with REAL model
dispatches where the continuation semantics demand them.

## Acceptance criteria

1. The application rides the public SDK boundary with a
   repository-reproducible, secret-free configuration and executable
   tests; the corpus declares, per row, the submission pattern (duplicate/
   conflict/retry/escalate/continue), the expected ledger outcome and the
   expected effect multiplicity (exactly-once semantics).
2. Deterministic fixtures make every offline row reproducible; the
   duplicate/conflict rows need no provider at all (ledger-level).
3. A REAL end-to-end integration run over REAL PostgreSQL drives every
   row: duplicates REPLAY (identity preserved, zero new effects, replayed
   flag surfaced); conflicts get the typed IDEMPOTENCY_KEY_REUSED
   rejection; retries journal per-attempt history with exactly-once
   effects; escalations land at the declared authority with the causal
   chain; continuations resume exactly once with stale-worker denial and
   no-op-resume replay (the VAL-014 precedent's ledger-key discipline).
4. Effect multiplicity is verified mechanically against fixture state
   (side-effect counters, journal sequence continuity — gapless).
5. Honest economics and latency; payload digests (never payloads) in
   evidence.
6. Discrimination tests prove the semantics against controlled fakes
   (forged replay claims, journal gaps, double-resume attempts, escalation
   loops).
7. Evidence document records REAL outcomes, timings, costs, NOT RUN
   boundaries and the executed battery honestly.
