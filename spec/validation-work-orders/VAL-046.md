# VAL-046 — Substrate/Runtime Economics (Readiness, Startup, Reliability)

**Status:** AUTHORIZED / PENDING (eligible now: VAL-044 complete — the adjusted-cost families exist; owner: Lead session B per the 55a3b69 lane coordination)

## Objective

Deliver the substrate/runtime economics: the cost of the substrate itself.
Measure and verify the compute-substrate economic facts — readiness
(warm-up to first-usable), startup (cold-start to ready), sustained
runtime overhead and reliability (failure/eviction/restart frequency and
their amortized costs) — then compose them into the economic comparisons
as an explicit substrate-cost family: substrate cost per run, substrate
cost amortized per resolved outcome, and the readiness-adjusted comparison
(a comparison that silently absorbs substrate cost into a provider price
FAILS mechanically). The substrate facts derive from RECORDED substrate
telemetry (the VAL-022 substrate failure/readiness records and the
platform's recorded run provenance); live rows (env-gated, BYOK, measured)
drive one REAL substrate-cost measurement over a REAL representative
substrate lifecycle with every priced input at its pinned manifest
revision.

The verification core: a substrate model that hides startup cost, ignores
readiness probing, conflates reserved capacity with measured usage, or
amortizes failures away FAILS mechanically (each probed adversarially in
the discrimination battery).

## Acceptance criteria

1. The application rides the public SDK boundary with a
   repository-reproducible, secret-free configuration and executable
   tests; the corpus declares, per row, the recorded input digests (the
   VAL-022 substrate records, the run provenance, the adjusted-cost
   results), the substrate-cost family under test and the expected
   verdict.
2. Deterministic fixtures make every offline row reproducible; recorded
   telemetry is referenced by content digest (never copied); every
   priced input's pinned price revision is verified against the VAL-040
   manifests.
3. A REAL end-to-end integration run (env-gated) drives one REAL
   substrate lifecycle measurement (cold start → ready → sustained
   runtime → teardown) with live facts: the substrate-cost families
   computed over measured facts, recorded through the REAL recorder with
   honest economics.
4. Mechanical verification per row: startup-cost inclusion (never
   hidden), readiness-probe honesty (first-usable, not
   first-dispatched), reserved/measured separation, failure
   amortization completeness (restarts and evictions counted),
   estimate/measure separation, confidence and minimum-sample
   enforcement — probed adversarially (a startup-hiding,
   readiness-inflating, reserved-conflating, failure-amortizing-away or
   below-minimum comparison each FAIL).
5. Honest economics and latency (measured on live rows, none-reported
   honestly offline); payload digests (never payloads) in evidence.
6. Discrimination tests prove the substrate families against controlled
   fakes (startup hiding, readiness inflation, reserved/measured
   conflation, failure amortization-away, post-hoc exclusion,
   sample-size violation, re-measurement masquerade).
7. Evidence document records REAL outcomes, timings, costs, NOT RUN
   boundaries and the executed battery honestly.
