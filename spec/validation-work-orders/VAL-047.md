# VAL-047 — Longitudinal Cost Curve and Cost-per-Successful-Outcome Improvement

**Status:** AUTHORIZED / PENDING (eligible now: VAL-045 + VAL-046 complete — the savings attribution and the substrate economics exist; alternation: session A lane per the 55a3b69 coordination readiness rule)
**Program:** Zeck Validation Roadmap
**Assurance:** HIGH_ASSURANCE
**Dependencies:** VAL-045, VAL-046

## Objective

Deliver the longitudinal cost curve: how unit economics IMPROVE (or fail
to) over sustained operation. Compose the recorded longitudinal history
(the VAL-030 frozen baselines, the VAL-031 replay trajectory analysis, the
VAL-032 discovered mechanisms, the VAL-036 maturity classification, the
VAL-045 per-mechanism savings attribution, the VAL-046 substrate
economics) into the longitudinal cost curve family: cost-per-successful-
outcome as a function of accumulated operation (per workload class, per
mechanism cohort), the improvement-rate decomposition (which mechanisms
drove which delta — reconciling against the VAL-045 attribution), and the
plateau/maturity verdict per workload class (improvement still trending,
plateaued, or never materialized — honest classification, never a
narrative). Every curve point carries its run identity (the VAL-007
immutable ledger), Wilson confidence, minimum samples and the pinned price
revision active at that point in time (price-regime changes are marked on
the curve — never silently normalized away).

The verification core: a curve that cherry-picks its window, silently
normalizes a price-regime change, extrapolates beyond its evidence,
conflates estimate with measurement, or hides a regressing cohort FAILS
mechanically (each probed adversarially in the discrimination battery).

## Acceptance criteria

1. The application rides the public SDK boundary with a
   repository-reproducible, secret-free configuration and executable
   tests; the corpus declares, per row, the recorded input digests (the
   longitudinal ledgers, the attribution results, the substrate facts),
   the curve family under test and the expected verdict.
2. Deterministic fixtures make every offline row reproducible; recorded
   results are referenced by content digest (never copied); every curve
   point's pinned price revision is verified against the VAL-040
   manifests and price-regime changes are marked, never normalized away.
3. A REAL end-to-end integration run (env-gated) drives one REAL
   longitudinal slice with live dispatches: curve points computed over
   measured facts, recorded through the REAL recorder with honest
   economics.
4. Mechanical verification per row: window honesty (no cherry-picked
   window — the declared window matches the recorded data), price-regime
   marking, no extrapolation beyond evidence, improvement-rate
   reconciliation against the VAL-045 attribution (exactly, no
   unexplained residual), cohort honesty (regressing cohorts reported as
   regressing), estimate/measure separation, confidence and
   minimum-sample enforcement — probed adversarially (a cherry-picked,
   regime-normalizing, extrapolating, residual-hiding or
   cohort-hiding row each FAILS).
5. Honest economics and latency (measured on live rows, none-reported
   honestly offline); payload digests (never payloads) in evidence.
6. Discrimination tests prove the curve families against controlled fakes
   (window cherry-picking, regime normalization, extrapolation,
   residual hiding, cohort hiding, post-hoc exclusion, sample-size
   violation, re-measurement masquerade).
7. Evidence document records REAL outcomes, timings, costs, NOT RUN
   boundaries and the executed battery honestly.
