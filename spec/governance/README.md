# Governance Artifacts

The governance model is intentionally repository-resident and machine-readable.

`architect.json` defines non-delegable authority.

`worker-protocol.json` defines the implementation worker contract.

`assurance-profiles.json` maps declared change surfaces to required proof depth.

`checkpoint-contract.json` defines blocking architecture fitness functions.

`future-roadmap.json` describes post-MVP evolutionary work and is not itself authorization to implement it.

All changes to frozen governance semantics require a Work Order and, when they cross the architecture boundary, an Architecture Change Request.
