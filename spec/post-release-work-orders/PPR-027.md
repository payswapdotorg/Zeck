# PPR-027 — Cross-Application Longitudinal Economics and Developer-Adoption Evidence

Status: PRE-AUTHORIZED / DEPENDENCY-GATED
Depends: PPR-020, PPR-021, PPR-022, PPR-023, PPR-024, PPR-025, PPR-026
Target: certified application portfolio

Run longitudinal experiments over the certified applications and their direct/strong-optimized non-Zeck baselines.

Measure at comparable quality/reliability/safety/latency thresholds:

- cost per successfully resolved outcome;
- quality-adjusted and failure-adjusted cost;
- median and tail latency;
- provider failure/retry rates;
- provider portability and time-to-add/change provider;
- customization coverage;
- deterministic/reuse/verified-computation rate;
- engineering surface removed from the application;
- capability-discovery-driven avoided implementation;
- telemetry/explainability completeness;
- incident diagnosis/recovery time;
- execution reproducibility;
- migration effort and time-to-certification;
- developer preference after sustained exposure.

Run the experiment across workload volume, active provider count, modality count and application maturity. Do not assume preference rises with scale; measure it.

The prior scenario percentages are hypotheses only. PPR-027 replaces them with observed distributions, uncertainty and reasons for developer choice.

Use ACR-007 when measuring whether application integration remains a thin delegation adapter rather than a shadow Zeck authority.
