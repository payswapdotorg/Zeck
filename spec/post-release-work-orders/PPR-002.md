# PPR-002 — Live Free-Tier-First Public Preview Deployment

**Status:** AUTHORIZED / WAVE A  
**Program:** zeck-post-release-public-productization  
**Base:** current governed main at dispatch

## Objective

Turn the repository's reproducible deployment recipe into a real reachable Zeck preview/sandbox deployment.

## Preview topology

- Vercel Hobby where personal/non-commercial terms permit;
- Neon Free authoritative PostgreSQL;
- Cloudflare R2 Free;
- Cloudflare Queues Free allowance;
- Cloudflare Workflows Free allowance;
- Upstash Redis Free;
- self-hosted/governed execution runner;
- self-hosted or usage-based OTLP.

## Required fact reconciliation

Before provisioning:
- update `deploy/manifests/provider-tiers.json`;
- verify current provider plan/limits/terms;
- record `asOf`, source and verification status;
- preserve exhaustion/degradation/upgrade/exit behavior;
- keep NOT RUN where account credentials are unavailable.

The existing ledger is explicitly recorded-not-live-verified and contains older limits.

## Deployment sequence

```
current main
→ account/credential preflight
→ provider-tier reconciliation
→ database + migrations
→ artifact store
→ queue/workflow
→ coordination
→ runner
→ public delivery
→ identity
→ health
→ public smoke
→ sandbox
→ validation rerun
→ browser acceptance
```

## Credentials

Request only the minimum required:
- Vercel project/deployment;
- Neon API/project;
- Cloudflare R2/Queues/Workflows;
- Upstash;
- DNS/TLS if required.

Never store secret values in Git or reports.

## Commercial boundary

Vercel Hobby is not the commercial production plan. Preview may use it only where its terms permit. Commercial production must use a permitted paid plan or alternate host.

## Completion

Require:
- public URL;
- exact revision identity;
- /health;
- /identity;
- public smoke;
- console smoke;
- first sandbox execution;
- provider/free-tier verification;
- rollback/repoint evidence.
