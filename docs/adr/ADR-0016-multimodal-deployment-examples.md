# ADR-0016 — Multimodal Deployment Examples

**Status:** accepted product clarification

Zeck's deployment fabric is intentionally general. The initial product examples are:

- voice receptionist / support agent
- website or in-app messaging agent
- SMS/WhatsApp-style conversational agent
- video-generation service/agent
- image-generation service/agent
- audio-generation service/agent
- document-processing agent
- vision-enabled support agent
- realtime multimodal assistant
- background/event-driven automation agent

These are examples of deployment profiles, not separate execution models. All retain the same policy, capability, budget, provenance, verification and execution authorities.
