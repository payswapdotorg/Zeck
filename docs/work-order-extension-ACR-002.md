# ACR-002 Work Order Extension Notes

ACR-002 adds deterministicization and selective human-evaluation capabilities as append-only extensions to the existing Work Order program.

## WORK-021
Owns discovery of recurring AI execution subgraphs that can be replaced by deterministic or hybrid computation, together with validation, shadow/canary rollout and rollback.

## WORK-022
Owns codebase-level opportunity analysis and selective human evaluation. It analyzes developer-supplied functions, traces and call graphs for AI addition/removal/deterministicization/hybrid opportunities and records rating evidence when automated evaluation is materially uncertain.

Both Work Orders preserve the existing Execution abstraction and authority boundaries.
