# Zeck Multimodal Deployment Roadmap

## Shared substrate

WORK-023 establishes the common deployment identity, profile, plan, lifecycle, promotion, rollback and upstream-rail abstraction.

## Channel and workload specializations

- WORK-024: Voice and realtime agents (web, telephony, SIP-style and future realtime rails)
- WORK-025: Messaging agents (conversational channels, attachments, delivery events and human escalation)
- WORK-026: Media generation agents (video, image, audio and multimodal generation with asynchronous lifecycle)

## Future expansion

The same deployment abstraction is intended to support document/vision, realtime multimodal, background automation and other specialized execution profiles without adding new top-level authorities.

## Strategic rule

Specialization belongs in profiles/adapters. Governance belongs in Zeck. Execution remains the common durable abstraction.
