## Issue findings and protocol

- **Stale-poll cursor defect (found by the first live run, fixed before commit).** Reproduction: driving task N+1 immediately after task N completed let the platform poll select task N's execution row before the new submission landed; the replayed transitions then collided on the planning-decision idempotency key (`IDEMPOTENCY_KEY_REUSED`, different fingerprint — decision ids are per-call), and the dangling application promise surfaced ECONNREFUSED after teardown. Classification: harness defect (test-side driver), not product. Fix: the poll cursor skips already-driven execution ids and waits for THIS task's row; the app promise is guarded so a drive-side failure can never dangle. Verification: the full suite rerun green (twice).
- **Oracle defect in the first transform criteria (found by the live run, fixed before commit).** The initial key-token oracle compared the source's top content words (e.g. "went", "looks") — words a register rewrite legitimately changes — producing false FAILs, and time reformatting ("2am" → "2:00") produced a false fabrication flag. Classification: validation-defect (oracle design). Fix: fact preservation is now mechanical over NUMBERS compared by value with clock-format canonicalization; fabrication = numbers absent from the source. Verification: discrimination tests (dropped-number FAIL, invented-number FAIL, faithful rewrite PASS) + the live rerun.
- **Provider geo-gating (carried from VAL-009):** flagship routes remain region-gated from this egress; open-weights routes (the llama-3.3-70b used here) route fine — recorded as provider-axis evidence only.
