## Issue findings and protocol

- **Seal-signature authoring defect (classification: validation-defect).** The first seal signature carried an unused `terminalStatus` parameter (the run-end event already owns it) — caught by the correctness linter (`noUnusedFunctionParameters`), fixed by removing the parameter; all call sites updated; battery re-run green.
- **Unsafe optional chaining (classification: validation-defect).** One test assertion used an unsafe optional chain — flagged by the linter, fixed with a null-safe default. Verification: typecheck + suite green.
- **Position-based trajectory diff semantics (classification: design note, not a defect).** The event-level diff matches by sequence position: an inserted mid-run event reports as a changed position plus an added tail event. This is the honest primitive for same-shape trajectory comparison; VAL-031 may layer a kind-aware matcher on top if longitudinal analysis needs it. Trade-offs recorded rather than silently changed.
