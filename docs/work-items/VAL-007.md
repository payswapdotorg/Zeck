## Issue findings and protocol

- **Tamper-detection gap (classification: validation-defect, caught by the own discrimination tests).** The first register() compared only the digest FIELD on re-registration — a mutated entry carrying the copied digest passed as "identical". Fix: content-vs-digest verification runs on EVERY register call (a copied digest with mutated content is a tamper). Reproduction: `register({...entry, hypothesis: "x"})` did not throw before the fix; it now throws `tamper detected`. Verified by two dedicated tests.
