## Issue findings and protocol

- **Realtime state-machine legality (found during the crown binding review, fixed pre-commit).** The stale-worker scenario's first draft issued a second `wait-user` while the execution was already WAITING_USER — illegal on the REAL frozen state machine (wait-user is legal only from RUNNING) and uncaught (it would have crashed the driver). Classification: driver-legality defect. Solution: the scenario now performs exactly one `wait-user` (RUNNING → WAITING_USER), the successor's `resume` (WAITING_USER → RUNNING), then the stale worker's `resume` from RUNNING — which the REAL state machine rejects with a thrown transition, caught and journaled as `resume-denied`. Verification: the unit suite's stale-worker assertions (exactly one denial, both turns dispatched exactly once) and the crown's ledger assertion (`resume-denied` events == 1 for `dlg-003`).
- **Lint hygiene (found during the post-resume verification pass, fixed pre-delivery).** The first implementation carried 10 lint warnings in the new files (5 non-null assertions on the roundtrip dispatch path, unused imports/parameters across the platform module and two test files). All removed by explicit narrowing/local capture — behavior-neutral (typecheck and the full battery re-run green after the change); the new files now carry 0 warnings and the repository warning count (44) is identical to the dispatch base's.
- **The in-code-synthesis honesty limitation (design decision, recorded).** In-code WAV synthesis can produce utterance-SHAPED audio, never intelligible speech. The synthetic STT rows therefore record their fixtures' DECLARED annotations with the observed transcript (oracle provenance is explicit), and the strong transcript-vs-ground-truth oracle rides the REAL roundtrip rows (REAL TTS speech transcribed by REAL ASR, verified against the phrase fixture's own terms). No synthetic clip is ever claimed to carry lexical content.
- **TTS byte-level ground truth (design decision, recorded).** Provider TTS payloads are not byte-stable across dispatches; the mechanical TTS verification is therefore container/codec validity + non-empty payload + digest capture (the digest proves WHAT was received, not what should have been received). Recorded honestly in the platform module's header and here.
- **Empty-transcript honesty rule (design decision, verified by unit + discrimination tests).** An ASR 200 with an empty transcript is an honest success with an empty transcript (silence-legitimate) — the synthetic utterance rows' transcripts may legitimately be empty on the REAL rail; the roundtrip rows' `transcript-present` criterion carries the non-empty requirement where the ground truth demands it.
