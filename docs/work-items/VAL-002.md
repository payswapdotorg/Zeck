## Design notes

- **The transport seam is the SDK's own `fetchImpl` injection point** — the harness holds no networking of its own (the benchmark tree is network-free by architecture rule); production runs inject the environment transport, tests inject controlled fakes or real clients against the served API.
- **The lifecycle is driven platform-side in the crown proof** — the application itself only rides public modes (create/poll/result); the seeded world plays Zeck's operators exactly as the production platform would (the canonical transition chain), so the customer boundary stays pure.
- **Result digest** is SHA-256 over canonical JSON (sorted keys) — deterministic across runs; `observedAt` never enters the run identity (VAL-001 contract).
