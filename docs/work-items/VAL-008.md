## Issue findings and protocol

- **Verdict-composition defect (classification: validation-defect, caught by the own tests).** The first composition let evaluator-method tasks return INCONCLUSIVE while a deterministic oracle (containsText) had FAILED — the rubric path masked the oracle failure. Fix: the deterministic oracles are the floor for every method (a failed oracle fails the evaluation before any rubric/tolerance consideration). Reproduction, impact, fix and verification recorded in the test discriminations.
- **Signal-less dispatch condition defect (classification: validation-defect).** The harness-family dispatch wrongly required a null terminal status; a completed-but-unfailing classification call dispatched nothing. Fix: the dispatch fires on empty signal sets. Verified by the dedicated test.
